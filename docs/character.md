# Задание №2. Фирменный персонаж — «Арчи»

Выбран путь №2 из ТЗ: своя идея, на которой строится сайт.

## Идея

Арчи — это сама арка здания, ожившая и ставшая хозяином пространства.
Вместо традиционного «человека в строгой одежде» персонаж воплощает главное
преимущество АРКА 123: **арочное окно с видом на Национальную библиотеку**.

- **Лицо — арочное окно.** В нём небо, плывущие облака и граненый силуэт Библиотеки
  (ромбокубооктаэдр, узнаваемая форма здания). Гость видит, ради чего приходят в пространство.
- **Тело — графитовая арка** с латунной окантовкой: цвет стен помещения из графитового ДСП.
- **Ноги — две колонны**, как два высоких дома, соединённых аркой.
- **Брошь-логотип** на груди — отсылка к брифу (брошь в виде логотипа) и фирменный знак.
- **Характер:** спокойный, гостеприимный, немного церемонный. Встречает, приветственно машет и «показывает» на вид из окна.

## Роль на сайте

- Встречает гостя в блоке «Об АРКА 123» и ведёт его по сайту.
- Идёт фоном по странице при скролле (задание №4): машет, показывает на окно, в разных блоках стоит в разных позициях.
- Живая анимация: дыхание, моргание, взмах руки, плывущие облака, пульсация броши.

## Реализация

Векторный SVG (`src/character.js`), без растровых изображений: не весит почти ничего,
чётко выглядит на любом экране и анимируется GSAP.

## Ограничения

Это статичная иллюстрация персонажа с лёгкой процедурной анимацией, не фотореалистичный
персонаж. Генерации изображений в моём наборе инструментов нет.
